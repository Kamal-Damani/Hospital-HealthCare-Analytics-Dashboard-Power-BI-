# 🏥 Hospital Patient Analytics Dashboard | Power BI

## 📊 Project Overview

The **Hospital Patient Analytics Dashboard** is an interactive Power BI dashboard designed to analyze and visualize hospital patient data.

The objective of this project is to transform raw healthcare data into meaningful insights related to **patients, diagnoses, medicines, hospital charges, admissions, and sales**.

The dashboard provides an easy-to-understand view of important healthcare KPIs and helps users explore the data interactively.

---

## 🎯 Project Objectives

- Analyze patient demographics and information
- Understand patient diagnosis trends
- Track hospital admissions and discharges
- Analyze medicine quantities and sales
- Monitor patient charges
- Create interactive healthcare KPIs
- Build an intuitive and user-friendly Power BI dashboard
- Convert raw data into meaningful business insights

2. Understanding the data structure

4. Handling missing values
5. Correcting data types
